# ADR-004: 适配器只使用公开 Hook/上下文入口，不写宿主私有记忆

## 状态

Accepted

## 日期

2026-07-23

## 背景

Claude Code 与 Codex 都有各自的原生记忆或上下文机制，但这些内部目录、文件布局与写入约束都不适合作为第三方产品的长期数据库接口。

## 决策

适配器遵循以下边界：

- 使用宿主公开生命周期 Hook。
- 使用宿主允许的上下文注入入口。
- 不把宿主原生记忆目录作为持续写入目标。
- 原生记忆在未来只可作为一次性导入源或只读参考源。

## 结果

优点：

- 降低因宿主升级造成的破坏。
- 明确 Mind Palace 是独立记忆层，而不是宿主补丁。

代价：

- 某些更深的宿主能力短期内拿不到。
