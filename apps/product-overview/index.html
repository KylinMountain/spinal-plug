The premise / 01

一个人的记忆，
不应困在一个工具里。

你在 Codex 做出技术判断，在 Claude Code 接着排查问题。以前，新的 Agent 是空白的；现在，它可以在启动时接入同一个项目记忆，并在工作后把真正有价值的经验回归中心。

01 — LOAD

加载身份

从 Project Space 取回关键规则、历史决策、项目背景与权威引用，形成受 token 预算约束的启动上下文。

02 — WORK

独立行动

每个 Agent 在自己的会话和设备上工作。它们不是共享隐藏状态，而是共享经过治理的项目经验。

03 — RETURN

回归记忆

值得长期保留的决定、纠正与上下文被发布为事件。其他 Agent 可预览、选择同步，再写入自身原生记忆。

Control flow / 02

不是同步文件，
是编译一段共同经历。

本地记忆、云端事实流与宿主原生记忆各司其职。事件是事实源，中心决定规范版本，宿主获得自己能理解的投影。
