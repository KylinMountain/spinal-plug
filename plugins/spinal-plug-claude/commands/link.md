description: Bind the current directory to an existing Spinal Plug archive by Space ID.
---

The user has selected an existing Spinal Plug archive. Use the provided Space ID and optional name:

```bash
spinal-plug link "$HOME/.spinal-plug/spinal-plug.db" . <space-id> "<display-name>"
```

Report that this directory will automatically load the linked archive in future sessions.
